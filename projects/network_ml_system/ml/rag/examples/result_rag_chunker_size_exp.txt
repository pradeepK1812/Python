------------------------------------------------------------
Engineering Conclusion
------------------------------------------------------------

A fixed chunk size should not be treated as the complete
chunking strategy.

Chunk size should be treated as a TARGET CONSTRAINT,
while semantic boundaries should guard the actual cut points.

A production-quality chunker should prefer boundaries in
the following order:

    Paragraph boundary
          ↓
    Sentence boundary
          ↓
    Word boundary
          ↓
    Character boundary (last resort)

The chunker should also prevent extremely small residual
chunks from being created.

Therefore:

    Chunk Size
         +
    Semantic Boundaries
         +
    Minimum Useful Chunk Size
         ↓
    Robust Chunking Strategy

Raw character-based splitting is unsuitable as a
production chunking strategy by itself.
