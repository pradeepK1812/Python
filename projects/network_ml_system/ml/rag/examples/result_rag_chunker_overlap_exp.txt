CHUNK OVERLAP EXPERIMENT — RUN 1
============================================================

Experiment:

Baseline:
    Semantic boundary-aware chunking
    Target-size chunking
    Minimum chunk-size constraint
    Rebalancing
    No overlap

Experiment:
    Same strategy
    One complete preceding sentence used as overlap
    Applied to every subsequent chunk within a section

Observations:

1. Sentence-based overlap successfully preserves a complete
   semantic unit from the previous chunk.

2. The overlap does not propagate recursively because the raw
   previous chunk is retained as the overlap source.

3. The first chunk has no overlap. Subsequent chunks may contain
   one complete sentence from the previous raw chunk.

4. Sentence overlap can increase the effective chunk size beyond
   the configured target size. For example, one chunk reached
   approximately 339 characters against a target of approximately
   230 characters.

5. Blind sentence overlap can introduce content from a previous
   knowledge unit into the next chunk. For example, HTTP context
   was carried into a chunk that also contained DNS content.

6. Therefore, semantic overlap preserves contextual continuity,
   but does not necessarily guarantee improved semantic coherence
   of the resulting chunk.

Architectural Observation:

Overlap should not be considered automatically beneficial simply
because it preserves context.

There is a trade-off between:

    Context Preservation
            vs
    Chunk Purity / Size / Redundancy

The current experiment intentionally applies one complete
preceding sentence at every applicable boundary to establish a
controlled baseline for measuring the effect of overlap.
