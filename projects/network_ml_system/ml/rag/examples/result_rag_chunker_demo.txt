HTTP uses TCP because it requires reliable and ordered delivery of web content over a connection. TCP provides this level of reliability, ensuring that data is delivered in the correct order and can be reconstructed on the receiving end if necessary. This is particularly important for web applications where data may be lost or corrupted during transmission, such as with DNS queries which typically use UDP due to their small request/response messages and low latency requirements.
