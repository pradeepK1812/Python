In machine learning, the basic idea is to use a model to make predictions from input data, compare those predictions with actual results to compute loss, use backpropagation to calculate gradients, update model parameters using gradient descent (or another optimizer), and repeat this process iteratively until the model learns the patterns in the dat

Soevery machine learning algorithm is essentially the following steps :

-> forward pass
→ loss
→ backpropagation
→ gradient descent
→ iterative learning
